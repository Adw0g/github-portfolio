## 🚀 How to Run Locally

You can open `index.html` directly in any web browser, or launch a lightweight local server:

### Using Python:
```bash
python -m http.server 3000
```
Then visit: `http://localhost:3000`

### Using Node / npx:
```bash
npx serve
```

## 🌐 How to Deploy to GitHub Pages (Free Hosting)

Deploy your portfolio live as `https://adw0g.github.io` in 3 simple steps:

### Option A: As your main GitHub Pages URL (`Adw0g.github.io`)
1. Create a new repository named exactly **`Adw0g.github.io`** on [GitHub](https://github.com/new).
2. Inside this portfolio folder, run:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio commit"
   git branch -M main
   git remote add origin https://github.com/Adw0g/Adw0g.github.io.git
   git push -u origin main
   ```
3. Your portfolio will automatically go live at **`https://Adw0g.github.io/`** within 1-2 minutes!

### Option B: In a repository named `portfolio`
1. Create a repository named `portfolio` on GitHub.
2. Push your files:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio commit"
   git branch -M main
   git remote add origin https://github.com/Adw0g/portfolio.git
   git push -u origin main
   ```
3. In GitHub, go to **Settings > Pages > Branch**, select `main` and `/ (root)`, then click **Save**.
4. Your site will be live at **`https://Adw0g.github.io/portfolio/`**.
